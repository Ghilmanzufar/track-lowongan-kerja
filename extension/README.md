# 🚀 JobTrack Web Clipper (Chrome & Edge Extension)

Ekstensi browser resmi JobTrack untuk menangkap lowongan kerja langsung dari **LinkedIn**, **Glints**, **Jobstreet / Seek**, **Indeed**, **Kalibrr**, dan website karir perusahaan ke database JobTrack lokal Anda.

---

## 🛠️ Cara Pasang Ekstensi di Chrome / Microsoft Edge / Brave

1. Buka browser (Chrome / Edge / Brave).
2. Kunjungi halaman ekstensi:
   - **Chrome**: `chrome://extensions/`
   - **Edge**: `edge://extensions/`
   - **Brave**: `brave://extensions/`
3. Aktifkan **"Developer mode"** (Mode Pengembang) di pojok kanan atas.
4. Klik tombol **"Load unpacked"** (Muat yang belum dibongkar).
5. Pilih folder:
   ```
   d:\Project\track-lowongan\extension
   ```
6. Ekstensi **JobTrack Web Clipper** akan langsung aktif dan muncul di toolbar browser Anda! 🎉

---

## 💡 Cara Penggunaan

1. Buka halaman lowongan kerja di LinkedIn / Glints / Jobstreet.
2. Klik ikon ekstensi **JobTrack** di pojok kanan atas browser.
3. Data lowongan (Judul, Perusahaan, Lokasi, Tautan, Sistem Kerja) akan terisi otomatis.
4. Pilih status (misal: *Disimpan* atau *Siap Dilamar*), lalu klik **"💾 Simpan ke JobTrack"**.
5. Data langsung masuk ke papan Kanban dan daftar lamaran JobTrack Anda!
